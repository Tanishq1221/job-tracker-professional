# 💼 Job Application Tracker

A responsive Job Application Tracker built with React.js that helps users manage and track their job applications in one place.

## 🚀 Live Demo

https://job-tracker-professional-ezpl.vercel.app/

## 📂 GitHub Repository

https://github.com/Tanishq1221/job-tracker-professional

## ✨ Features

- 📊 Dashboard with application statistics
- ➕ Add new job applications
- ✏️ Edit existing applications
- 🗑️ Delete applications
- 🔍 Search job applications
- 🎯 Filter applications by status
- 📄 View detailed job information
- 💾 Persistent data using Local Storage
- 📱 Responsive design for different screen sizes
- ⚡ Fast and modern React + Vite setup

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Vite

- React Hooks
- HTML5
- CSS3
- Local Storage
